# Technologie Arcanique d'Anastasius

Les condensateurs à **Résonance Éthérique** permettent aux nefs célestes du [[Synode d'Airain]] de traverser les brumes abyssales sans dérive cartographique.

:::secret[gm_only]
Chaque condensateur renferme le souvenir cristallisé d'un veilleur défunt ; briser le cristal libère un Spectre d'Entropie de rang 4.
:::
